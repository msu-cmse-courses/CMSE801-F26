# MSU - CMSE 801 (Introduction to Computational Modeling and Data Analysis)- Fall 2026
---
CMSE 801 is a graduate course exploring various aspects of computational science and a variety of practical, fundamental computational skills. The course will explore application-driven modeling of various systems, with applications to the physical, life, and social sciences, and also to engineering and mathematics. While we will learn some computer programming over this semester, the goal is utilitarian - this is a course in applied computing, rather than a course intended for traditional computer scientists!

### Course goals
---
- Gain insight into physical, biological, and social systems through the use of computational algorithms and tools
- Write programs to solve common problems in a variety of disciplines
- Identify salient features of a system that can be codified into a model
- Manipulate, analyze, and visualize datasets and use this data to evaluate models
- Have an understanding of basic numerical methods (e.g., numerical integration, differential equations, Monte Carlo) and be able to use them to solve problems
- Be able to take results from a scientific computing problem and present it both verbally and in writing
