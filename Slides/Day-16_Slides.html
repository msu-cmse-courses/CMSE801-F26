Questions/comments from Day 16 PCA¶

  • Coming up with what story to tell with your data visualization can be challenging.
    • The plot should do more than just represent a basic statistic or something that could easily just be shown with a small table.
    • The visualization to create opportunities for insights not capture by the data alone.

Questions/comments from Day 16 PCA (cont.)¶

  • Seaborn can be a bit tricky to use as first, just like any new package, it takes time to digest the documentation and learn to use it.
    • When you get stuck trying to use a new tool, as always, googling the issue you're running into can be a good way to find examples that do something similar to what you're trying to do.
    • Seaborn can also be used as a simple way of changing the style of basic matplotlib plots. We'll look at an example.

It's important to think critically when we're presented with data visualizations¶

  • Make sure to ask yourself:
    • What story is this visualization trying to tell?
    • What might this data visualization be hiding?
    • What do I need to know about the data in order to more deeply understand the visualization?

In order to determine the best way to visualize your data, you need to spend time exploring it!¶

  • Try visualizing the data in more than one way.
  • Think about whether or not you're interested in the relationships between features in your data, how the data varies with time, or something else!
    • Perhaps you need to use one or more features to create a new feature that is derived from the original ones.
  • Explore the types of visualizations and think about which ones might be the right choice for the story you're trying to tell.
    • The Data Visualisation Catalogue is a great tool for this. Try the "Search by Function" feature.
